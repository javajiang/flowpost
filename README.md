# FlowPost

## 目标

做一个面向内容创作者和小团队的工具，核心流程是：

1. 导入原始内容
2. 结构化改写
3. 适配不同平台
4. 多平台发布

## 我们要做什么

- 接收内容源
  - 第一版：文本、图片
  - 第二版：RSS
  - 后续：URL、文档、笔记
- 把原始内容整理成可发布草稿
- 根据不同平台自动改写语气和长度
- 生成多平台版本
- 支持排期和多平台发布
- 后续可以加入审核、协作、分析和自动化

## 导入功能

- 第一版先做文本导入和图片上传
- 所有导入内容先进入一个主草稿
- 第二版再做 RSS 订阅和自动抓取
- 后续扩展 URL、文档、笔记等来源

## 我们的差异化方向

- 内容导入比竞品更顺
- 结构化改写更强
- 平台适配更自动
- 更适合中文团队和中英双语场景
- 更强调“从原料到发布”的完整链路

## 我们之前讨论过的重点

- Postiz 更偏内容生产 + 排程发布 + 自动化 + 自托管
- Buffer 更偏成熟的社媒发布与协作平台
- 我们不直接卷“全平台覆盖”
- 优先做“导入 -> 改写 -> 适配 -> 发布”的转换层
